## Required change (blocking, single item)
src/debrief/adapters/ggufbench_store.py:126 — `except FileNotFoundError, NotADirectoryError:` is not valid Python 3 syntax on stock CPython (`SyntaxError: multiple exception types must be parenthesized`; the Python-2 form was removed in 3.0 per PEP 3110 and stock interpreters — including CPython 3.14, which this project pins via `.python-version` and `requires-python = ">=3.14"` — reject it). I confirmed the line verbatim on disk (grep + Python repr of line 126). Notably, this sandbox's interpreter, ruff and mypy all accept it, so every gate here is green — but the artifact built from this tree is unimportable on stock interpreters, which kills the `debrief` console script entirely: no bench.query responses of any kind, i.e. R1 and R3 fail in deployment even though they pass in this sandbox. It also silently changes meaning in the dialect where it parses. The parenthesized form `except (FileNotFoundError, NotADirectoryError):` is the documented intent. The line is inherited from parent commit 922409d (git status shows the adapter unmodified in this feature), so a one-line `fix(debrief): parenthesize multi-exception except in ggufbench adapter` commit resolves it; no test changes needed.

Everything else is approve-quality; re-run the gate battery after the fix and this slice is done.
